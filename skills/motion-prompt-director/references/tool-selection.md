# 根据方案选择工具，不让工具替代导演

制作工具按用户指定、已有工程和实际环境选择。Remotion、HyperFrames 等属于可选制作／渲染路径，具体动画库属于实现层。当前默认关闭三维与CSS立体产品表演；明确例外以当前任务范围为准。动态图形、大画布运镜、图谱叙事是表达方式，不归属于某个插件。工具中立不等于每次都换工具或强制混用。

## 选择依据

1. 用户指定与现有工程：指定Remotion就保留；既有项目局部修改优先沿用。确有无法满足的要求时说明具体限制与替代，不自行迁移整片。
2. 已选表达所需能力：对象层级、路径／遮罩、镜头与大世界、二维图形变形、素材播放、可定位时间等。很多能力不独占于某一工具，不声称“换框架必然更高级”。
3. 已有环境与素材：实际可用的版本、依赖、渲染资源、透明格式与兼容性；先做必要的能力小样，未验证不宣称可用。
4. 交付与后续编辑：源代码、参数、预览、视频规格、alpha、音轨与可复用程度；不能只看预览能播。
5. 成本与收益：单工具能完成就避免无收益的多引擎。混用时记录谁驱动时间、谁渲染、哪些部分只能作为像素素材编辑。

## 可考虑的路径与文档

- Remotion：现有React／逐帧工程、组件与参数复用可能适合；按真实项目检查。技术入口见[Composition官方文档](https://www.remotion.dev/docs/composition)与本包[交接](remotion-handoff.md)。不默认所有对象都做卡片。
- HyperFrames（HF）：HTML合成与逐帧输出、时间线组织可能适合；按真实环境检查。[官方介绍](https://hyperframes.app/docs/1-startup/1-introduction)。不因为它有组件库就照搬标题／字卡模板。
- 其他二维代码动画与真实图片素材：需要相应能力时考虑；当前不自主制作或以三维产品动画片段绕过立体禁用。不得凭空声称已安装、已验证或所有平台可编辑；可以把必要局部渲染后合成，明确像素素材的编辑边界。

链接用于核对能力与当前API，不是动态参考观察证据。上述是选择依据，不是速度、质量或美感排名。选用前查实际版本与当前官方文档；本包不随附第三方引擎，不保证离线安装。

## 跨工具仍生效

默认无说明文字、仅Logo原生字标、不朗读／配音／临时TTS计时的约束跨工具生效。明确图表任务的必要真实数值／标签、真实界面演示中的操作文字、指定文案修改及产品名，按 SKILL.md 的任务范围处理；不由工具模板自动扩大授权。三维与CSS立体禁用也跨工具生效，只有当前明确要求才按范围例外。需要其他工具技能且目标环境可用才读取；缺少该技能用可访问官方资料，不能要求另一AI一定存在本机路径。

记录一小段选型理由：选中方案需要什么→现有环境能做什么→为什么采用此工具→未验证风险。未指定工具不要求完整比较所有软件，也不默认HF或Remotion。创意阶段可做能力试探，但不能按某个模板最方便倒推整片。
