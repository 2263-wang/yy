# 动作索引与组合配方

本库含 60 张提示卡与 12 个组合配方。提示卡描述目标画面，不等于完整可执行组件。8 个基础代码组件在 MotionKit.tsx；compose 表示可用其组合起步，spec-only 表示还需专门实现与验证。数值为初始建议，不替代用户要求。

当前默认仅Logo原生字标可见，遵从[无文字MG](nontext-mg.md)。文字、数字、标注动作及R06／R07／R08等依赖文字的部分默认不执行；保留为用户显式文字任务的资源。其余配方也应去掉额外标题／名单／标签，不以卡片页面切换代替对象事件。不朗读文案，不用TTS估时。

先按[组合探索](exploration-method.md)与真实参考展开表达方法，选定方向后按[分类](animation-languages.md)检索细节，再读当前动作类别。动作库属于局部实现词汇，配方不是穷举边界，不先用数量和效果名称决定整片表达。

## 组合配方

- **R01 单主体清楚展示**：E04 → F05 → O01。揭示主体 → 显示一个确有价值的细节或标注 → 收回。缺少细节素材时用原图局部，不补造内容。
- **R02 多图展开与揭示**：E03 → L01 → F08 → L06 → O02。叠放建立数量 → 展成清楚布局 → 按阅读顺序交接焦点 → 收拢或沿原方向退出。
- **R03 二至三对象并列集结**：E05 → L08 → F08 → O05。错峰抵达共同布局 → 逐个短暂介绍并交还同等分量 → 回到并列 → 干净退出。轮换不表示排名。
- **R04 较多素材分组展示**：E04 → L01 → L04 → O03。按用户顺序分组 → 保持同一布局规则换组 → 汇总或收回。素材多而时长短时明确密度限制，不静默遗漏。
- **R05 从群体中揭示主角**：E03 → L01 → L10 → F01 → O04。先明确群体 → 其他元素让位或抽离 → 目标对象成为主角 → 收紧识别。只在用户有主角意图时使用。
- **R06 真实数据排名变化**：E04 → L05 → X05 → F06 → O03。建立标签与数据绑定 → 数字、条长与位次同步变化 → 终值停留 → 收回；缺少数据时列出待填字段，禁止编造。
- **R07 数字与证据说明**：X03 → X05 → F06 → O03。提出真实数值或结论 → 展示相应证据 → 标注重点 → 留阅读时间。证据缺失就标待补。
- **R08 文字与图形接龙**：X01 → T09 → T01 → X03 → O04。关键字出现 → 一处轮廓接到图形 → 新构图建立 → 回到可读标题。路径不兼容时用遮罩替代真实变形。
- **R09 大世界连续讲解**：E04 → T06 → L09 → F06 → O06。同一世界布置内容站点 → 停站或跟拍表达 → 沿空间关系接到下一站 → 汇总或回起点。
- **R10 透明剪辑转场**：T05 → T04 → O03。透明起始 → 前景扫过并完全遮挡切点 → 继续运动退出 → 完全透明；不保留底板。
- **R11 图标对象状态与容器衔接**：E03 → L08 → F08 → T01 → O04。建立可识别的图标初态 → 围绕同一触发展开、切换或交接焦点 → 稳定呈现整体或回收容器。按对象关系分组；环形只是可选布局，不能代替状态逻辑。
- **R12 低干扰氛围循环**：M01 → M02 → O06。循环成片从首帧已清楚的主体开始 → 低幅周期变化 → 位置、尺度、alpha与速度接回首态。需要揭示入场时将它另放循环段之外。
