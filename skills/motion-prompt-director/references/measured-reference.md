# 量测过的参考：六张海报 · 堆叠炸开 → 相机呼吸 → 主角抬升

这条案例不是随手写的示例，是对一支真实成片逐帧量出来的。用途：当用户说"做成那样的动效"却给不出参数时，用这里的数字当默认值，而不是凭形容词猜。

## 量测方法（可复用）

1. 取到源片，`ffprobe` 确认分辨率/帧率/时长（本例 1920×1080 / 30fps）。
2. `ffmpeg -ss <t> -i <src> -frames:v 1` 抽全分辨率关键帧，先看清画面构成。
3. 密集抽帧看节奏：`-vf "fps=8,scale=430:-1,tile=6x4"` 做接触表，一拍一张图，比看视频更能读出节拍。
4. 要尺寸不要肉眼：把帧转成亮度掩膜，按行/列做投影找连通带，再在格子内求包围盒。得到的是真实像素，不是估计。
5. 不要用 `cropdetect` 量卡片位置——背景有噪点，它会一路报整幅 1920×1080。

## 时间结构（源时间码，合计约 6.7s）

| 段 | 时间 | 时长 | 发生什么 |
|---|---|---|---|
| 1 | 76.02–76.20 | 0.18s | 黑场 |
| 2 | 76.20–76.35 | 0.15s | 环境微光起；六张以"一叠"出现，小到只看得见最上一张 |
| 3 | 76.35–77.05 | 0.70s | 一叠炸开，落到 3×2 网格；逐张错峰仅 2–3 帧 |
| 4 | 77.05–79.40 | 2.00s | 相机推近：从满幅网格推到上下越界 |
| 5 | 79.40–80.20 | 0.80s | 相机退回满幅 |
| 6 | 80.20–81.60 | 1.40s | 再推近（峰值略小于第一次） |
| 7 | 81.60–82.00 | 0.40s | 退回 |
| 8 | 82.00–82.75 | 0.75s | 第 6 张抬到前景，其余降调后退，聚光出现 |
| 9 | 82.75–82.95 | 0.20s | 停在主角，随后切走 |

## 几何（1920×1080 画布，实测）

- 卡片 **302×378**（4:5），六张完全同尺寸。不是各自比例、不是高矮错落。
- 列心 **575 / 959 / 1337**，列距 **382 / 378**。
- 行心 **338 / 743**，行距 **405**。
- 由此得出：**横向间隙 79px，纵向间隙只有 27px**。横向留白是纵向的约 3 倍——这是它看起来"松而不散"的原因，也是最容易做错的一项（多数人做成四边等距，立刻显得呆板）。
- 每张卡有 **±0.5–1.3° 的固有倾角**，网格并不绝对水平。这点倾斜是"手摆"感的全部来源。
- 推近峰值时内容越出画面上下各约 **40px**，折合相机倍率 **≈1.45–1.48**。
- 主角段：主角卡约 **562×715（≈1.86 倍）** 居中；其余五张约 **0.9–0.95 倍**，亮度压到 **35–40%**，并向外散开约 7–10%。

## 光（最容易被漏掉的一层）

- 底色是 **#060607–#0a0a0a**，不是纯黑。
- 卡片背后有一层很低强度的环境光晕，从入场起就在，全程不变。
- 主角段出现**径向聚光**：中心透明，四角压到约 0.85 黑。
- **层序是这个效果成立的关键**：聚光必须在"被压暗的五张"之上、"抬起的主角"之下。放错一层（压在全部卡片之上），主角自己的边缘也会被削，整个节拍就塌了。这一条不写出来，实施者几乎必踩。

## 五条可复用的判断

1. **展开不是扇形**。它走的是"一叠 → 各自最近的格位"这条最短路径。扇形展开、绕弧排布是最常见的过度设计，会把一个干净的揭示变成展览墙。
2. **相机呼吸是骨架**：推 → 退 → 推 → 退。每一次推都是为了让下一次"落回"有对比。少了退，片子从头到尾顶着一股劲，观众在第 3 秒就疲劳。
3. **主角节拍要三层同时成立**：位置（归到中心）+ 尺寸（1.86×）+ 光照（聚光、其余降调）。只放大不给光，主角立不住；只给光不放大，观众不知道该看谁。
4. **错峰只有 2–3 帧**，层次是靠缓动（back.out 类）拉开的，不是靠时间差堆。加大错峰会直接变成"发牌"。
5. **收尾不是回到网格，是停在主角**。回网格是安全的收法，但也把上一拍的力气卸掉了。

## 本案例的素材现实

六张海报是从源片帧里裁出来的（主角卡用它在最大可见时刻的帧，542×715，比网格时期清晰一倍）。这意味着：

- 卡片的圆角、边缘高光、以及那点固有倾角**已经烘焙在图片里**。复刻时不要再给卡片加圆角或额外旋转，否则会双重叠加。
- 如果用户的素材是干净的原图，圆角/阴影/倾角需要自己在合成里补；这两种情况的图层写法不同，交付时要问清是哪种。

## 与默认建议值的关系

本技能别处给的"8 秒 / 1920×1080 / 30fps"是针对无参考的短动效的兜底。一旦拿到参考片，**以量测值为准**；本案例的真实时长是 6.7 秒而不是 8 秒，节拍比例也不是均匀分配的。

# 案例二：章节卡「Part. 01 / Remotion 的优势」

同一支片子的另一段（源 6.9–8.3s）。这是"设计软件选区"母题的另一种用法：标题不是被排出来的，是被**框选**出来的。

## 实测几何（1920×1080）

| 项 | 实测 |
|---|---|
| 画布网格 | **80×80px** 细线，交点上还有小点 |
| 背景 | 深海军蓝，四角更亮、中心偏黑；左上角最亮 #2238a8，暗部到底 #070b22 |
| 选择框 | x 360–1559（1200 宽）× y 330–749（420 高），**4px** 线，色 **#B6E23A** |
| 角手柄 | 30×30，4px 描边，深色填充 |
| 高亮块 | x 371–836（465）× y 355–472（117），色 **#6D3ECF** |
| 「Part. 01」 | 白 900 斜体，约 108px，落在高亮块内 |
| 标题 | 「Remotion的优势」约 146px，左起 x≈393 |
| 光标 / 徽章 | 同色 **#C8F02B**；徽章是深色字、浅色底，左下方贴光标 |
| 品红双向箭头 | **#A836B7**，位于 (262–370, 218–326) |
| 紫色圆点 | **#8742EF**，位于 (825, 296)，落在高亮块右端上方 |

## 实测节拍

- 选框在**上一场就已经画好**，本段开场是静止的框。
- 7.00s 高亮块从左侧出现，宽度从 0 起。
- 7.00–7.35s 高亮块左→右扫过约 0.35s；「Part. 01」**被同一个遮罩同步裁出**。
- 7.35s 标题以约 30% 透明度出现，7.45s 到纯白。
- 7.50s 装饰（箭头、两个星芒、徽章）弹入。
- 7.55–8.30s 停住。

## 五条判断

1. **高亮块既是色块又是文字遮罩**。做成"块放大 + 文字打字"两套动画，两者一错开就露馅；必须同一个 `clip-path` 同步推进。
2. **边框先画、手柄后弹**。手柄跟边框一起出现显得廉价；先闭合矩形，再让四个角"咔"一下到位。
3. **装饰最后入场、幅度最小**。箭头、星芒、徽章都是文字落定之后的注脚，抢在标题前面就变成噪声。
4. **光标和徽章同色、徽章字用深色**，一眼看出是同一个人的光标；徽章用浅底深字，不要反过来。
5. **网格必须够淡但不能没有**。它承担"这是一块画布"的语义；去掉就退化成纯色底，整个母题就没了。实测线宽 1px、透明度约 0.1 量级。

# 案例一的重做数据（曲线驱动版）

第一版是"普通"的做法：直线位移、无蓄力、`back.out` 一次性过冲、无挤压、位置/旋转同刻到位、错峰按数组下标。后果是没有力，像贴纸。

重做版把每个通道写成解析曲线，渲染和审计读同一份函数（`motion-curves.js`），所以下面的数字就是画面里的数字，不是另测的。

| 指标 | 旧版 | 重做版 |
|---|---|---|
| 弧线度（最大垂距 / 行程） | 0% | **13.0%** |
| 落位过冲 | 一次性 `back.out`，无衰减 | **3.4% 过冲后回落** |
| 回弹次数 | 0 | **2** |
| 挤压峰值 \|scaleY−1\| | 0% | **7.0%** |
| 挤压时面积波动 | — | **3.0%**（面积近似守恒） |
| 旋转跟随滞后 | 0 帧 | **2 帧** |
| 六张卡到位分散 | 0（同时） | **0.10s**（按行程级联） |
| 起步速度 | 4.38/s（陡起） | **0.03/s**（从静止加速） |
| 相机接缝最大速度突变 | — | **0.013**（≈0，数值误差量级） |

## 曲线长什么样

- **行进**：加速 → 越过目标 3.5% → 回落 → 停住。三段都用平滑阶跃（两端 v=0），所以起步、过冲极值、终点三处速度都为 0，与蓄力段、相机段都能对上 C1。
- **弧形**：`sin(π·progress)` 作为垂直于行程方向的偏移曲线，两端为 0，与直线通道共用同一时间窗，合成一条真正的弧。
- **挤压**：飞行中沿运动方向 `+4.5% / -2.8%`（面积微增 1.6%），落位瞬间 `-7.5% / +6.4%`（面积微减 2%），随后回 1。
- **相机**：四段 `sine.inOut`，每段两端 v=0，接缝处跳变 0.013，等于连续。

## 结论

"普通"不是审美问题，是**这些指标里有六项是 0**。把这六项从 0 改成有值，观感立刻从"贴纸排布"变成"有质量的东西在动"。
