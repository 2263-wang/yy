# 动画参考研究：主动搜索、实际观察、迁移到设计

研究用于弥补表达与动作设计不足，直接参与候选形成，并可在探索中反复进行。它不只是选好主线后查教程。当前默认仅Logo原生字标、无说明文字、不朗读／配音／TTS；参考中的文字、声音与工具偏好不自动转为本题要求。

## 当前表达参考过滤

原创表达检索限定二维MG、图片蒙太奇、平面Logo／产品图交接、剪纸拼贴与大画布二维取景。当前关闭以三维机身、金属打光、悬浮转台、环绕镜头或CSS透视开合为主体的参考。不是换成HF／CSS就可绕过。

主题词与表现形式一起搜，例如“iPhone Duo 二维 产品图片 快切 MG 转场”“product photo montage 2D flat motion design match cut -3D -CGI”。排除词只是初筛；实际画面以立体展示为主就不纳入当前候选，继续找平面方法。若同一作品存在可单独迁移的平面段落，记录实际观察的段落和方法，不把整支三维片当当前风格目标。

这个过滤针对表达学习，不针对事实与素材：真实产品照片、官方静态渲染可作为平面素材，已有透视和光照允许保留；不能因此停止搜产品图或用低质量自画机身替代。参考中的产品名只在用户明确要求名称时迁移，不附带大段字幕。

## 三种检索分工

- 内容／素材：企业、事实、环节、Logo与图像。核对身份与依据，不等于学会动画。
- 表达：别人怎样表现这个题目或同类结构，怎样组织整体与局部、依赖、时间与因果、焦点和衔接。它负责打开方法范围。
- 实现：选定方法怎样用当前工具实现。API和代码帮助落地，不能代替对画面组织的研究。

有联网工具时，原创未定主线要针对表达缺口做研究，主题、态度与运动机制都可作为入口。已有适用的用户参考或配方可先观察并打样，有未解决缺口再补研究；局部修订／明确复刻不强制重新全面搜索。用户明确禁止联网时遵守并说明研究依据。没有工具或网络失败时走降级，不伪造执行。

## 按表达缺口选择参考入口

主题、表达态度与动作机制可以并行检索。同题作品不是唯一入口；降低过度正式感时，可从独立动画、音乐影像、漫画分格、杂志拼贴或日常物体运动学习迟疑、打断、重复、材料关系和观看预期。仍需观察真实片段并说明如何迁移到当前内容；不能只贴“手作／实验／去AI味”标签。

已有明确参考风格或匹配的 DrawAI 镜头卡时，可读取配方／源码并观察参考，先移植关键动作做小样；不强制再做一轮全面检索。来源缺少动态画面时如实标范围，用自己的小样检验时序，不把代码阅读说成看片。

需要理解题目如何被组织时，可搜与主题相关的动画、动态信息图或作者拆解，不只搜资料。例如本题是AI产业链，可尝试：

- AI产业链 二维MG／平面动态图谱 案例；AI supply chain flat 2D explainer animation。
- 同题结果稀少、质量不足或只有课件时，扩展：半导体供应链 平面动画、manufacturing supply chain flat motion design、complex system 2D explainer。
- 发现具体缺口后再搜：大画布关系图 运镜、animated diagram overview detail、assembly continuity、signal flow cause response。

这是示例检索词，不是声称已有这些作品。其他主题用实际内容替换，不把AI产业链变成通用检索词。跨题材迁移的是组织方法，不复制事实：制造流程的视觉交接可以借鉴，但不能把推理请求编成经过制造企业的真实流水线。

先看解决整体组织问题的完整片段，再补局部教程；不以“高级科技感”“苹果风格”替代具体问题。可以从作者作品、作品集、作者拆解与官方演示发现方法。搜索不限Remotion／HF、不限本库分类；实现文档优先官方来源。不要因第一个结果容易做就锁定方向。

## 真实观察与迁移记录

用户关注画面设计或运动曲线时，同时研究关键构图和动作时间分配，按[画面设计与运动曲线](design-and-motion-curves.md)选择少量可定位区间。构图区分主体尺度、主次、色彩角色、材质、层级、留白和裁切；运动区分对象、取景、尺度、形变等属性及其起停与错峰。需要曲线细节时按原生帧率观察可追踪特征，记录误差与区间；只看稀疏抽帧不能认定精确缓动。量测结果、拟合建议与作者原始参数分开，不要求每个参考都做数值拟合。

选择少量能回答当前问题的片段，通常1–3个有效观察就能推进，不按链接数量达标。研究记录包含：

1. 实际执行的查询、来源标题／作者、URL或本地文件、相关区间。
2. 实际查看范围：正常速度播放／逐帧／截图／仅文字／访问失败。摘要、封面、播放命令都不能冒充看过动态。
3. 观察到的起态→变化→终态，主角、空间参照、对象与镜头分工、焦点怎样交接；附真实取得的帧／截图路径或平台区间。未量测不编秒数、相机坐标、弹性参数或作者工程结构。
4. 本题如何迁移、必须改造什么、哪些事实／数字／颜色编码／商标情节不借，以及进入哪个候选或为何排除。

用户希望学习丰富度时，另外辨认参考里有哪些视觉内容、可见事件、表示形式与尺度／密度变化，哪些来自素材内部，哪些来自外层编排；指出靠什么保持统一和完成段落交接。把这些方法映射到本题需要的素材与状态，不能只提炼成一种转场或产品演示顺序。按[片内丰富度设计](visual-richness.md)迁移，[Kimi案例及跨题材推演](richness-cases.md)给出观察范围与边界。

至少一个有依据的表达方法应进入候选或改变比较；已查看但全部不适配就继续寻找或说明限制，不能硬用。列链接、截图墙、复制作者风格词、先确定方案后补“已借鉴”不算迁移。参考可能确认已有方向，也可能引入新方向，不要求为了显得不同而改动。

## 访问失败与诚实降级

失败后换可访问来源、结构相近题材或用户已有片段；不要反复请求用户提供参考。仍只能读文字时可用作者讲解作为方法依据，动态表现待验证，用自制小样验证本题实现。包内完整示例可保住工作进展，但不能充当“网上搜索完成”的证据。

记录真实尝试、未能观察什么、替代依据与未验证项。允许继续已授权制作，不能把受限研究写成已通过，也不能无说明跳过搜索。关键表达仍不成立就重新设计；确实无法选择有效方向时再请用户决定。

## 已有起点的边界

[Apple · Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)与[Material · Choreography](https://m1.material.io/motion/choreography.html)可帮助研究对象连续性与焦点衔接，不能包办所有主题的整段组织。本包此前依据是官方文字材料，不声称重新观看过完整视频；交互参数不升级为预渲染动画通用阈值。

用户给过的产业图谱参考不随包分发。[旧图谱粗动稿](diagram-narrative.md)含说明文字，仅作技术参考；[无文字MG粗动稿](nontext-mg.md)为自制局部练习。新题仍需有针对性研究，不把少量内置示例作为方法边界。

## 已整理的产品片与抽象广告

画面与曲线从[视觉与运动研究](design-and-motion-curves.md)进入；对象交接、控制反馈、任务接续、跨版式成果、轮廓匹配和材料动作另见[产品片与抽象广告方法](product-film-studies.md)。全片概览、加密抽帧与原生帧量测各有证据范围，原片未随 Skill 分发。它们可以扩展候选，不要求新任务先复现整套发布片。
