# 大世界与摄像机

这是用户提出的核心结构：内容放在一张足够大的纸上，摄像机按路线取景。输出画幅只决定录制范围，世界可以更大。

## 适用判断

内容确有空间联系、需要连续穿行，或用户明确要求一镜到底时优先采用。少硬切、整体平移是参考线索，不能单凭一个信号断定内部实现。独立页面、单主体叠加和角色表演可选择其他结构。

## 坐标与取景

世界坐标放置内容；摄像机位置 c=(cx,cy) 和倍率 z 决定取景；屏幕位置为：

`screen = viewportCenter + z × (worldPoint − cameraPosition)`

相机包裹层可写成 translate(W/2-cx*z,H/2-cy*z) scale(z)，原点设为 0 0。需要跟随世界的灯光与遮罩置于世界层，字幕或 HUD 如需固定则放取景框层。不要重复缩放子层坐标。

## 路线

先写每次取景的观看任务，再定路线。总览、局部、前景接管与返回是可选职责；镜头不必沿目录逐层巡览。稳定图谱中只改变部分关系的显著程度也成立；当前默认仅Logo原生字标，不能另加全景说明小字。对象与当前关系需要可识别。[旧图谱粗动稿](diagram-narrative.md)含文字，仅作技术参考；大平面世界是跨工具的表达方法，不被Remotion或HF独占。

列出站点、取景范围、关键帧和移动／停留区间。按用户提出的方式，可在停站时播放主体动画；也允许预备动作在镜头抵达前开始，或用跟拍让内容与镜头共同运动。

停到停可用 smooth。连续经过的路径节点要用保持切向速度的插值，不能每个节点都强制 v=0。停站是否推近由表达决定，稳定构图也成立。

## 可见性验证

取景范围随倍率变化，水平半宽 W/(2z)、垂直半高 H/(2z)。在移动开始、中途及结束采样，用实际内容包围盒检查投影、遮挡与留白。斜向路线还需检查纵向覆盖。

旧例的站距 0.8–0.9×W、公式 d≤W/2+r、非纸色面积 40%，仅是那个布局的经验检查，不能保证任意路线无空白。内容半径、下一站布局、倍率和视觉目的都影响判断。必要时缩短路线、调整站点或加入有意义的中间内容，不为过百分比随意堆纸片。

同一角色若代表同一个连续对象，应避免无意重复；比较图、多副本或分身表达可以重复。退出后的隐藏按后续可见性和用途决定，不要求所有出画对象永久 alpha=0。

## 模糊

CSS blur 是各向同性的高斯模糊近似，不是真正的方向性运动模糊。旧式 min(线宽×4,速度×0.13) 只可作为该案例的起始参数。

计算屏幕点速度应包含平移与变焦：对采样点比较相邻帧投影。纯变焦也会产生速度。不同位置可能有不同位移；真实运动模糊还受曝光时间／快门、方向与时间采样影响。需要准确效果时使用时间采样或引擎提供的运动模糊，避免把半径公式当物理定律。
