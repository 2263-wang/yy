# 三个动作案例

当前边界：只用二维路径；旧例中的透视／三维、材质打光等建议不执行。真实产品图可作平面素材，图片蒙太奇与明确获准产品名按[主规则](../SKILL.md)处理，不把技术示例当默认成片。

以下是用于说明输出深度的原创重建示例，不是原视频画面的复原，也不代表作者 Skill 的原文。素材内容、数值和风格服从实际用户输入。

## 六张海报：展开、聚焦、归位

用户输入：“我有六张海报，做一个有设计感的展示动效，不要像 PPT。”

制作判断：图片本身是视觉主体，采用 2D 加轻 2.5D 卡片运动，靠共享空间和前后层次组织注意力。

可执行方案示例：

- 建议规格：8 秒、1920×1080、30fps、普通不透明成片；明确这些是建议值。图片按实际上传顺序记为海报 1–6，不假设图片内容。
- 0–1.2 秒：六张卡片从中心叠放状态向两侧展开为浅弧，按 0.09 秒间隔启动；轻微倾斜形成前后层次，最后一张到位后整体减速。
- 1.2–3.2 秒：相邻卡片有序换位，焦点交给中间两张；保留每张海报的运动轨迹，不退场后替换另一套页面。
- 3.2–5.3 秒：前景卡片向两侧让位，一张主海报沿深度感方向接近镜头；旁侧素材缩小并降低强调，主海报保持可读。
- 5.3–6.6 秒：主海报退回，六张共同归位为 3×2 网格，先运动后统一收稳。
- 6.6–8 秒：停留展示完整海报组，留足剪辑连接空间。
- 图片按原比例展示；需要填充卡片时先检查裁切是否切掉标题或主体。可编辑项包含图片列表、卡片尺寸、间距、倾角、错峰和主海报编号。
- 避免逐张静态海报加淡入淡出，避免装饰效果覆盖海报正文。背景、配色和字体在看过素材后再确定。

## 排名动效：数值变化与位置交换一致

用户输入：“按这张排名参考图做一个冲刺动画，右边可以改内容。”

先检查参考图：实际数据、排名方向、名称与头像对应关系、终态布局。不把演示性分数写成用户真实数据。

方案需明确：

- 按用途决定横向条形排名、纵向卡片或其他已见参考结构，不凭“排名”两字强行套同一个模板。
- 列表进入后，数值开始变化；条长、数字和名次的变化使用一致的数据进度。位置交换要保留对象身份，避免名字与头像交叉错配。
- 冲刺高潮集中在一次关键超越，其余元素降低动作幅度；最终顺序与终值数据一致，并停留供读取。
- 需要起始与最终数据却没有给出时，明确待填数据，或在用户允许演示数据时使用标注的样例。只有一张终态图不能证明真实变化过程。
- 可编辑：条目列表、起始值、最终值、标签、颜色和冲刺节奏；调整数据后要重新计算排序与布局。

## 透明转场：覆盖与退出有明确状态

用户输入：“做一个一秒半的透明转场，放到剪辑软件上叠着用。”

制作判断：用 2D 几何遮罩即可。透明画布上仅有运动图形，不设置不透明底板。

- 0–0.5 秒：多条色带从画面左侧错峰扫入，先窄后宽，覆盖率连续增加。
- 0.5–0.75 秒：色带短暂完全遮住画面，为剪辑切点提供遮挡窗口。
- 0.75–1.5 秒：色带沿原方向退出，逐渐露出下层画面，结尾全部离开，恢复完全透明。
- 色带的短暂全覆盖是转场动作，不是固定背景；起始与结尾不能留有可见残片。
- 可编辑：主辅色、扫动方向、错峰、覆盖停留和出入速度；改变总时长要同步合成元数据。
- 用户要求交付时输出带 alpha 的 MOV；仅需方案时给出导出约定，不声称已经导出。具体设置读 [Remotion 交接要点](remotion-handoff.md)。
