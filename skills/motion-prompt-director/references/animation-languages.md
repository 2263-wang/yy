# 按内容与表达目的选择动画语言

当前入口先按[组合探索](exploration-method.md)展开与内容相关的多种组织方法，再用本页检索细则。类目不是唯一答案或穷举边界；“怎么选”的优先关系是检索启发，不授权在探索前锁定主导语言。参考学习可引入库外新方法。实现工具另按[工具选择](tool-selection.md)决定。

先识别内容中的关系，再决定画面用什么方式表达。文件类型、素材数量、分辨率和时长是后续约束，不先用它们决定创意。

当前用户默认[无说明文字动画](nontext-mg.md)，只有Logo原生字标可见。ML06文字语义及需显示数值／标注的方向，只有用户本次明确要求对应文字才启用；分类不能覆盖画面规则。不要将ML03空间导览等同目录巡览。文案不朗读、不TTS。

这是本技能的工作分类，不是穷尽的学术分类。「苹果式对象动效」是用户偏好的参考语言，不是苹果官方分类，也不等于必须加回弹、毛玻璃或照搬系统界面。「摄像机叙事」是组织观看路径的方法；两者可以组合。

## 四层决策不要混在一起

进入分类前先确定片段职责，原创新设计按[制作方法](production-method.md)展开与比较画面命题，再执行[设计检查](design-review.md)。可先检索多个相关类别，比较后再确定主导。选中类别只完成检索；既不默认第一概念，也不证明已设计。无法依据构图／小样可靠取舍时，带具体候选与不确定点请用户选择。

1. **主导语言**：由当前段落的内容关系与表达目的决定，比如对象状态、事件推进、机制因果、数量比较；整片可贯穿一种语言，也可按阶段改变主导，不规定全片同一布局。
2. **组合与辅助语言**：按片内观看任务组合图片编排、对象事件、角色、群体或取景等表达，明确统一项与交接依据。比较后继续设计候选内部，不把其他语言永远限制为装饰；语义文字仅限用户本次明确要求文字的范围。见[片内丰富度设计](visual-richness.md)。
3. **视觉风格**：极简、纸片、液态、手绘、像素、写实等另选。液态既可能是外观，也可能是受力材质，按实际表达区分。
4. **实现方式**：Remotion、HyperFrames或其他工具按环境与交付选择；当前只走二维路径，关闭三维／CSS立体模拟，不因工具不同豁免。

## 十三类入口

- **ML01 [图标与界面：对象状态语言](languages/object-state.md)**：同一对象在出现、选中、展开、切换、归位之间改变状态。
- **ML02 [连续事件与历程：时空叙事语言](languages/time-process.md)**：内容自身具有阶段、先后或因果关系，观众需要沿过程前进。
- **ML03 [地图与场景：空间导览语言](languages/spatial-navigation.md)**：位置、距离、方向、邻接或层级是内容的核心。
- **ML04 [结构与原理：机制解释语言](languages/mechanism.md)**：内容要解释部件如何协作、输入如何产生输出，或内部结构如何工作。
- **ML05 [数据与比较：数量编码语言](languages/quantitative.md)**：观众关心多少、差多少、比例、趋势或位次变化。
- **ML06 [文字与观点：语义排版语言](languages/semantic-type.md)**：内容核心是句子、观点、关键词、对照或论证关系。
- **ML07 [接触与材质：物理因果语言](languages/physical-causality.md)**：推挤、碰撞、堆叠、牵引、回弹或材质受力本身就是要表达的事件。
- **ML08 [角色与情绪：表演语言](languages/character-performance.md)**：观众要读懂角色在看什么、想什么、怎样反应或行动。
- **ML09 [产品与细节：质感揭示语言](languages/product-material.md)**：观众关心物体的轮廓、材质、结构、使用部位或产品细节。
- **ML10 [图片与合集：编辑式编排语言](languages/editorial-collection.md)**：内容是多张图片、作品、卡片或海报，核心是并列、主次、归属与观看顺序。
- **ML11 [情绪与音乐：氛围节律语言](languages/atmosphere-rhythm.md)**：作品要传达情绪、氛围、音乐动机或可持续观看的循环。
- **ML12 [转场与叠加：剪辑衔接语言](languages/editing-bridge.md)**：动画承担连接镜头、遮挡切点、补充标注或为剪辑留余量的任务。

- **ML13 [品牌与抽象概念：图形修辞语言](languages/symbolic-brand.md)**：内容核心是标识、品牌特征、抽象关系或需要通过图形让人理解的概念。

## 怎么选

先写清楚「内容是什么、观众要理解／感受什么」。对象状态变化优先 ML01；内容自身有先后和阶段时优先 ML02；地理位置和空间关系优先 ML03；工作原理优先 ML04；数量变化优先 ML05；观点语义优先 ML06；受力与材质事件优先 ML07；角色反应优先 ML08；产品细节优先 ML09；图片关系优先 ML10；情绪和音乐动机优先 ML11；剪辑衔接优先 ML12；标识特征或抽象概念优先 ML13。

多种内容同时存在时，以表达目的选主导，其他作为承载素材或辅助语言。图标可以用于解释流程、数据或人物故事；连续事件也可以用固定画面变化讲清楚。默认路线帮助选型，不把内容类型与手法硬绑定。不适配时显式描述新内容关系，再建立补充方向；选择器拒绝未知别名，不代表该类动画不能做。

「有时间坐标」指内容本身的真实时间、阶段或因果，并非动画播放器的秒数。任何动画都有播放时间，这不能独立证明应该运镜。

有 Node 时运行：

```text
node scripts/select-language.mjs --content=icons --intent=state --objects=16 --files=1 --duration=8 --mode=insert --format=prompt
node scripts/select-language.mjs --content=icons,timeline --intent=sequence --duration=8 --mode=insert
```

第一条进入对象状态语言；第二条以事件推进为主、图标作为承载对象。命令只确定方向、给出概念候选与实现入口，不读取素材，不替代逐拍时间设计，也不生成视频。没有 Node 时按上面的语义判断选对应文件，只读当前相关类。

## 创意优先，完成度独立检查

按本用户偏好，先比较**画面表达是否值得做**：想法来自素材的哪个特点、核心趣味是什么、动作之间为什么这样接。再比较**能否做完整**：素材清晰、对象可追踪、节奏自然、衔接与输出正确。布局变化多、代码规范、帧率高和字清晰，不直接等于设计创新。

每类有两套概念候选，合计26套，用来启动思考；不是新增26个可执行组件。候选若只有淡入／滑入／弹入的差别，应说明这是动作手法比较；需要设计探索时还应比较不同画面命题。用户已给明确设计时优先按用户设计完成，复杂度和候选数量按任务决定。

选定语言后，再取用[60张动作卡与12套组合配方](motion-library.md)。已有配方只覆盖部分方向，不能把角色表演、真实结构仿真或材质动画说成已经有一键实现。具体实现边界在每类说明中列出。

## 三个边界例子

- 同样16个应用：做对象选中、展开、回收，主导ML01；解释消息如何经应用流转，主导ML02或ML04；表现触碰后的连锁响应，主导ML07。先选目的，再决定是否需要环、网格或镜头。
- 同样一张照片：讲地点与路线可用ML03；讲人物情绪可用ML08（需表演素材能力）；只保持氛围可用ML11。文件后缀不能完成这个判断。
- 同样一句文字：解释观点是ML06；文字仅是图标名称时应服务ML01／ML10，不自动升级为中心口号。
