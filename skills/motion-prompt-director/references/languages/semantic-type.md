# ML06 文字与观点：语义排版语言

内容核心是句子、观点、关键词、对照或论证关系。

## 主导方式

按语义组织字词、断句、重音与构图；图形作为词义的延伸。

## 节奏

读句时间与强调动作分开；关键词有重音，其他文字给它让位。

## 应保留的关系

- 语义与断句
- 阅读顺序
- 字词身份
- 观点依据

## 常见机械化问题

- 所有字按同一速度弹跳
- 添加通用口号，把输入主体挤成配角

## ML06-1 一个关键词带出观点

画面命题：让关键词的动作体现它在句中的意义。

- 开场：关键字或短语建立问题。
- 中段：其尺度、排布或形态引出完整句子与必要图形。
- 结尾：回到可以读懂的观点终态。
- 衔接：词义变化有依据，重音不破坏整句阅读。

## ML06-2 对照关系形成结论

画面命题：通过位置与节奏表达两种观点的关系。

- 开场：两组短语按可读顺序出现。
- 中段：共同参照下并置、替换或合并，突出真正差异。
- 结尾：留下结论与必要前提。
- 衔接：对照需要真实内容，不能用排版制造用户未表达的对立。
