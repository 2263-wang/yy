# ML01 图标与界面：对象状态语言

同一对象在出现、选中、展开、切换、归位之间改变状态。

## 主导方式

按用户偏好以苹果式图标／系统动效为默认参考：身份连续、动作有触发、质量感统一、落定明确；回弹和材质效果按目的选。

## 节奏

响应、推进、坐实与阅读分开安排；允许安静停留，群体按关系分组，避免逐个复读同一强调。

## 应保留的关系

- 对象身份与锚点
- 容器与子对象归属
- 关注对象交接
- 对象让位与回收

## 常见机械化问题

- 环绕标题成为无依据的默认方案
- 给所有对象持续呼吸或相同回弹，削弱主次

## ML01-1 容器展开与归位

画面命题：用对象的归属关系组织展开，观众先理解整体，再看成员。

- 开场：容器或收拢状态建立数量与共同锚点。
- 中段：由同一触发展开；成员沿近邻路径进入分组布局，保持图标正立与身份。
- 结尾：保留清楚整体或回收到原容器，按剪辑用途处理退出。
- 衔接：容器边界、成员锚点和视觉大小跨段承接；需要原顺序时用分组让道。

## ML01-2 焦点接力与空间让位

画面命题：一个对象获得关注时，其他对象通过让位解释当前状态。

- 开场：先建立稳定、均等的对象集合。
- 中段：选中对象抬升或展开其内容，邻居短距离让出空间；焦点交还后再换对象。
- 结尾：回到稳定整体；临时强调不暗示排名。
- 衔接：展开内容与原图标共用身份，回收时落回可追踪位置，避免所有对象同时抢焦点。

## 实现入口与边界

可参考动作：E03、L08、L06、F08、T01、O04，见[动作库](../motion-library.md)。已有配方可作为局部起点：R11、R03；需按本类表达改写，不自动继承原配方全部段落。

基础组件能搭图层状态与容器变化；不自动提供实时手势系统或完整系统UI。

这些是设计语言与提示方案，不是新增代码组件。返回[分类入口](../animation-languages.md)。
