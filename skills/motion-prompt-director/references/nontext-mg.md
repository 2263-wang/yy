# 无说明文字的MG：用可见事件表达

当前用户排除PPT式制作。默认成片只有Logo原生自带字标，其他标题、字幕、名单、注释、数值、英文装饰和结尾口号都不出现。方案和日志正常写文字；禁止把这些说明照搬进画面。不朗读口播、不生成配音、不调用TTS计时。

## 区别在于画面靠什么推进

当前采用二维动画、真实图片序列、图形修辞、剪纸／拼贴与大平面画布。画面可通过对象变化，也可通过图片选择、匹配剪辑、节奏与焦点交接推进；不要求每张静态图都内部变形。关闭三维与CSS立体模拟，详见[二维与蒙太奇](flat-montage.md)。

不用标题和名单组织每一页，不以机械等时换图、容器重复滑入或目录停站替代设计。有内容顺序、构图匹配、快慢与停留的图片快切允许，不能因使用照片或硬切直接否决。静止、矩形、图标容器本身不被禁止；它们作为对象参与状态／关系变化时仍可使用。把片名写成“MG”不能使版式巡览合格。

## 从短文案到图形事件

1. 写观众要理解的变化与信息优先级，别把“记住所有厂商”自动加入开场。选择少量可识别对象；品牌身份可用真实Logo，原生字标允许。
2. 为关键关系分配动作：连接／依赖可用支撑、牵引、联动和响应；阶段可用同一对象的状态继承；整体与局部可用组装、揭示或尺度转换。颜色／方位不凭空编码真实国家能力差距。
3. 比较有效方向时就使用无说明文字构图。不先做文字版再删字，否则常留下空版式。对象代理应保留最终身份、尺寸和遮挡关系。
4. 给主要变化做起态、中段、终态证据：谁触发、谁响应、什么被保留、焦点如何交接。若只有机械翻页而无观看作用，重做命题；蒙太奇以跨图关系、节奏累积和焦点交棒验证。
5. 检查信息是否还能辨认。不要求无声动画独自证明整段口播的所有事实，但当前目标和可见关系必须成立。表达不下时减少次要信息、改动作或请用户在有效方向间选，不自动补文字。

## 参考学习的方向

先搜适合本题的完整MG／物体叙事片段，再按需查局部教程。可用“无文字 MG 图形叙事 组装 动作衔接”“motion graphics visual storytelling object transformation no text”等组合，补具体对象。不能只看一个UI过渡就认为已学会整段组织，也不把只靠大字的文字动效当本次默认参考。

记录参考中具体动作如何改变关系；迁移到本题的关键变化应能在粗动稿定位。图形隐喻与事实分开，不把品牌画进芯片内部便声称真实物理包含。参考的文字元素不随动作方法照搬。

## 可运行的无文字粗动稿

示例在 `assets/story-examples/nontext-mg/`，代码和时间配置共享。两个方向使用同一批抽象模块：A表现模块组装再传递响应；B表现已有网络中的激活传播。没有企业Logo、数字、字体、字幕或声音，节点不代表真实企业和工艺。

它用于判断对象身份、可见变化、因果先后与衔接，不是AI产业链专用答案，也不是成片美术质量标杆。替换真实Logo／物体后重新核对事实、比例和路径。

将整个示例目录复制到已有Remotion工程 `src/nontext-mg/`，使用项目依赖。本例以React19.2.3／Remotion4.0.539验证，注册为1920×1080、30fps、240帧：

```text
npx remotion studio src/nontext-mg/entry.tsx
npx remotion render src/nontext-mg/entry.tsx MGAssemble out/mg-assemble.mp4 --scale=0.5
npx remotion render src/nontext-mg/entry.tsx MGPropagate out/mg-propagate.mp4 --scale=0.5
```

半尺寸预览为960×540、8秒，实际成片没有文字和音轨。技术接触表可以有时码，但它属于检查文档，不是视频素材。

- A：[组装与响应预览](../assets/story-examples/nontext-mg/assemble-preview.mp4)；[抽帧接触表](../assets/story-examples/nontext-mg/assemble-contact.jpg)。
- B：[激活与传递预览](../assets/story-examples/nontext-mg/propagate-preview.mp4)；[抽帧接触表](../assets/story-examples/nontext-mg/propagate-contact.jpg)。

两段都只是可运行的粗动稿，不作为所有内容的固定模板。已验证渲染、无音轨、关键状态与目标响应顺序；技术检查不代表美术质量或其他AI的实际执行效果已经达标。

## 素材、文字与声音检查

- 原生Logo可以含文字；自行排版的公司名、额外口号和说明不能因此豁免。
- 实拍、截图、包装或水印中的显著非Logo文字也需要检查；不要只查React文字节点。
- 对话和DIRECTION里记录内容、来源和观看任务；交付画面默认不带这些字。
- 禁止生成TTS，包括“只为获得口播时长”的临时配音；语义估时不等于真人同步。
- 类型、渲染、DOM文字检查只能覆盖各自范围。仍需看真实图像／视频，检查烘焙文字、身份、路径和关系。
