# 案例：纸面拼贴教学片（实测）

一支 34 秒中文动效教学片的逐帧量测结果。它演示的正是「过冲」和「重叠动作」，
所以它的画面本身就是这两个原则的执行样本。

**用途**：需要"纸面/手绘/教学"质感时的默认参数来源；也是检验"节奏对比度"的对照基准。

---

## 一、可直接复用的视觉参数（实测，非估算）

| 元素 | 实测值 |
|---|---|
| 画幅 | 1440×1080（4:3），30fps |
| 纸底色 | `#DCDBDB`，噪点标准差 16 |
| 青色方格 | 910×682 px，8×8，格子 **114×85.2（非正方形）** |
| 网格色 | `#B0D3DA`，线宽约 3px |
| 黄色轨迹线 | 倾角 **31.5°**，宽约 7px，贯穿整幅 |
| 黄线色 | `#DDD44F` |
| 数字卡 | 黑卡 + 米色数字，旋转 8–9° |
| 光标 | 经典箭头，白填充黑描边，投影偏移约 (5, 7) |
| 硬切点 | 34 秒 **0 个** |

**要点：格子的横纵比是 1 : 0.75，不是正方形。**
它不承担"精密对齐"的职责，只提供"这是一张方格纸"的语义。
做成正方形会变成工程图，失去手写感。

---

## 二、运动节奏（10fps 采样，阈值 0.6）

| 指标 | 数值 |
|---|---|
| 运动段数 | 27 段 |
| 时长中位数 | 0.20s |
| 最短 / 最长 | 0.10s / 3.3s |
| 落在 0.3–1.0s 区间 | **仅 15%** |
| 能量峰值 | 16.4 |
| 能量谷底 | 0.10 |
| **峰谷比** | **166 倍** |

---

## 三、修正「0.3–1.0s 阈值」的口径

原先把它当成统一阈值是错的。实测证明要按对象分类：

| 对象 | 合理时长 | 是否缓动 |
|---|---|---|
| 单个元素动作（飞入、缩放、旋转） | 0.3–1.0s | 要 |
| 笔迹 / 标注 / 描线 | 0.1–0.3s | **不要，匀速才像笔** |
| 镜头运动（机位移动、推拉） | 0.5–3s，可更长 | 要 |
| 多元素编排（逐个入场） | 单元素合规即可，总长不限 | 各自决定 |

---

## 四、新增判据：节奏对比度

0.3–1.0s 这个阈值保证的是**不显廉价的下限**，它不保证**有节奏**。

如果每个动作都精准控制在 0.3–1.0s、镜头一直在缓慢移动，得到的结果是
"每个动作都对，但整体平"——这是最常见的失败形态。

**判据**：

- 每个段落之间必须有一处能量 **< 0.3 的真静止**（不是"慢慢动"，是真的不动）
- 每个段落必须有一处能量 **> 3 的冲击**
- 全片峰谷比应 **> 30 倍**（参考片 166 倍）

验证方法见 `replication-process.md` 的帧间像素差流程。

---

## 五、转场（⚠️ 本节结论已被推翻，见文末更正）

参考片 34 秒零硬切，段落之间确实"连"在一起。实测接缝处约 **0.3s**，中段 2–3 帧完全糊掉。

**当时的结论**：有效做法是"小幅快速位移 + 峰值模糊处交叉溶解"。

**三种失败做法**（都试过）：

| 做法 | 失败原因 |
|---|---|
| 两页同时半透明 + 高斯模糊 | 糊成一团，像镜头失焦而不是甩动 |
| 出页淡出、入页错开淡入 | 淡出比滑走快，中间露出空白纸 |
| 三页并排成胶片带、镜头平移 | 中段必然扫过前一页的空白区域 |

另一条坑：**入页在转场第一帧之前就以不透明度 1 渲染，会把出页整个盖住。**
页面可见性必须精确对齐转场起点。

> **更正**：上面三种做法失败的真正原因不是手法选错，而是**这个问题本来不需要转场**——
> 参考片是「一张大纸 + 摄像机移动」，两段是同一张纸上的两处，镜头走过去而已。
> 一旦改成世界/取景框分离的结构，这三种失败全部消失，因为不存在"两页"。
> 详见 [世界与取景框](world-and-camera.md)。**遇到"转场怎么调都不对"，先怀疑该做成运镜。**

---

## 六、新增判据：视觉系统的一致性

参考片用五种元素贯穿全片，不换：纸面、青格、黄线、数字卡、手绘标注。
新内容进来（照片、插画、卡片）都贴在**同一张纸**上，所以混搭不脏。

这叫"统一材质"，不是"统一风格"——比统一配色更能压住杂项。

---

## 七、局限（同一个指标的固有缺陷）

帧间像素差把「改变的面积」和「运动速度」混在一起：

- 六张卡同时动，面积上必然赢过一张卡放大。所以"叠摞"会测出比"主角揭晓"更高的能量，
  但观感上揭晓才是高潮。
- 大幅模糊转场会造成度量假象（峰值 27 而不带任何戏剧性）。

**结论：这个指标能证明"段内有攻击/衰减、段间有排序、接缝连续"，
不能证明"观感上哪一下最重"。最终仍需要人眼确认。**
