# 完整保底实例：三图并列，透明叠加

对应 R03。直接使用 `assets/motion-kit/ThreeImageFallback.tsx`，不需要重新发明运动。只接受3个真实图片来源，图中附带的文字视为素材。透明背景不会自动移除图片自身的实色背景。

## 以8秒、1920×1080、30fps为例

- 基准中心：A1=(460.8,561.6)，A2=(960,561.6)，A3=(1459.2,561.6)。每个容器宽441.6、高669.6，用 contain 保持图像比例，透明部分也计入原图尺寸。
- 开场约0.14–1.04秒：按 A1→A2→A3 错峰短距离托入。alpha从0到1，scale从0.90到1。画面先有轻微错落，再于1.08–1.60秒对齐基线与角度。
- 中段1.76–6.32秒：按 A1→A2→A3 每个约1.52秒交接焦点；单次强调的推进和交还各约0.36秒，中间留阅读。放大到1.045；每次交还基准布局，不产生排名。
- 结尾6.72–7.63秒：短距离向外／向下离开并渐隐，最后保留透明余量。首帧、末帧alpha为0，不能把棋盘格渲染进去。

上述坐标为默认相对布局换算，不覆盖素材实际视觉重心。主体长宽比或透明边距差异很大时，先规范裁边和视觉大小，检查是否需要单独微调。

## 使用

将真实图片放入工程 public，对每项用 staticFile('实际文件名.png') 得到 src。注册 Composition 的 component 为 ThreeImageFallback，defaultProps 为 `{assets:[{src:...},{src:...},{src:...}]}`，durationInFrames 为用户要求秒数×fps。不要把省略号当实际代码路径。

完整代码在 [ThreeImageFallback.tsx](../assets/motion-kit/ThreeImageFallback.tsx)。时间随合成时长变化，默认8秒最合适；小于3秒会要求换成更简单的一拍方案。它只展示三张整图，不提供角色肢体表演，不自动添加背景、阴影或字幕。按真实图像检查宽高与构图后再导出。
