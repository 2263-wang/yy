# 片内丰富度：内容、素材、事件与编排

适用于需要丰富画面、参考学习、多段原创或出现机械重复的任务。核心是扩大内容可见的展开方式，同时保住主题、身份与观看顺序。一个清晰的短动作、安静循环或已有方案的局部修订，可以只用一种语言。

## 先区分两个设计层级

- **整片方向比较**：比较整体如何组织内容，沿用内容约束、外部研究、组合与剪枝；不靠颜色或曲线差异凑候选。
- **片内组合设计**：每个有效方向内部，继续设计内容载体、可见事件、表示形式、景别、密度与动作的展开。确定主导语言不意味着各段必须使用同一版式。

统一素材处理、线条／形状规则、色彩角色与运动质感；根据观看任务改变表达方式。允许一种语言连用，只要状态、关系或情绪有所发展。不同语言的接合需要共同主体、形状、锚点、方向、内容或节奏线索，不随机拼接库里的效果。

## 把抽象内容展开为可见事件

先说明观众要认识、确认或感受什么，再找到可见的主体和变化。按内容关系分段，不机械地一句文案对应一页，也不替短文案补造结论。

例如“多人协作”可以展开为：少量成员建立身份 → 更多成员进入 → 为当前任务选出小组 → 各组进入不同工作状态 → 成果汇集。是否需要这些阶段取决于题目；内容只支持并列集结时，不追加执行和成果。

可从以下关系找事件：出现与发现、选择与排除、整体与局部、拆分与组合、输入与反馈、比较与差异、积累与释放、变化与回访。将“高级、丰富、展示能力”落到可见起态、变化与终态。氛围片可发展纹理、色面、图像联想和群体节律，不必每拍解释流程。

动作来自主体特点与内容关系。工牌可介绍成员，紧凑名单便于选择，任务条显示执行，预览展示成果；这是按职责换表示形式的一个例子，不是所有内容都要包装成UI。

## 素材决定能展开多少内容

区分：真实产品／成果素材、可编辑的图形或分层素材、明确的抽象示意，以及只用于粗稿的代理。查看真实内容，确认裁切、尺寸、比例、可见细节和内部动态；不要仅凭文件名设计。

每个主要段落在现有节拍记录中补全这些结果即可，无需另写长文档：

> 观看作用｜主体与表示形式｜可见事件｜素材及取得状态｜素材内部／外层编排各做什么｜尺度、密度与停留｜与前后继承及变化的依据。

素材状态写已取得、可生成／可构建但待验证，或缺失；代理有明确替换对象。需要有设计的网页、图表、插画或照片，就先准备能承载细节的内容，再安排展示。缺关键素材时先补来源、制作内容或改表达，不能将没有内容的圆角框当作成品。

允许原创图形和虚构场景作为明确示意；真实产品界面、成果、性能和事实不得补造。素材内文字仍遵守当前文字范围。不能靠模糊全部内容来掩盖缺少证据，也不能用不明缩略图数量冒充能力规模。

## 同时看内容内层与片子外层

- **内层**：网页局部响应、角色行动、路径形成、图形重组、选中与完成等主体自身的变化。若声称展示动态成果，粗稿应包含相应内层事件；整张截图漂移不能代替它。
- **外层**：图片选择、顺序、裁切、尺度、分屏、群体布局、取景与剪辑。照片蒙太奇可以依靠这些关系成立，不强制让每张静态图片内部变形。

两层可以配合。主事件发生时给必要的识别空间；背景与外层动作不持续争抢焦点。复杂素材允许先看整体再看局部，不让重要内容只存在于不可辨的全景。

## 让段落之间有发展

从主体／素材、表示形式、构图与取景、对象关系、数量与密度、动作句式、动静与停留等维度检查变化，选与内容相关的维度即可。变化可以是同一世界里的发展，不必换背景或强制换镜头。

例如先用图片集合建立印象，再用单个对象的变化让人看清细节，随后给群体布局形成规模，最后聚焦成果。另一主题可能全程固定取景，通过内部状态推进。快段后的停留、密集后的留白、运动后的落定，都可形成对比。

重复可以建立母题、并列、节律或积累；在重复中决定保留什么、发展什么、何处收束。不要把“相邻段不同”执行成每段换一套无关美术。也不把所有方案都套成输入、协作、成果的产品演示。

## 用实际画面检查

先连看覆盖主要段落与转折的关键状态，必要时看整段粗动稿；已选方向仍可回到素材与事件设计调整。检查：

- 是否只有容器和镜头在动，而声称的主体变化没有发生？图像蒙太奇另按真实序列与匹配关系判断。
- 连续段落是否只换名称、颜色和数量，观看方式与内容关系都没有发展？若重复有节律或比较用途，说明实际作用。
- 计划中的素材细节、局部事件、群体状态和成果是否真实进入画面？若被统一模板抹平，修画面或改计划。
- 有没有以截图堆积、装饰数量或不停运动替代内容？焦点与必要的识别／停留是否仍成立？

失败时定位具体时段，补素材、改事件、调整表示形式或段落组织后复查。不要自动叠粒子、回弹、辉光来补救。使用语言数、效果数、镜头数或像素差不能自动给丰富度判分；静帧只证明构图与状态，正常速度回看才补充时间感验证。

完整例子见[丰富度案例](richness-cases.md)。案例中的时长、配色、成员数和素材类型均不是全局默认值。
