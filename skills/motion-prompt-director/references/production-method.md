# 制作方法：内容、研究、组合与验证共同形成方案

硬约束以SKILL.md和用户当前要求为准：默认仅Logo原生字标、不朗读／配音／TTS、不采用PPT式版式巡览。当前只做二维动画、图片蒙太奇与图形编排，关闭三维／CSS立体模拟；工具中立，先确定值得表达的内容与序列，再决定怎样实现。

## 1. 把内容变成约束

记录用户原文、用途、规格、交付形式、已定方案、可用素材和本题的表达态度。分别记录用户硬要求、事实依据、表达目标、实现条件与假设。问句或“来告诉你答案”不授权虚构答案、排名和差距数据；产业依赖线不自动表示采购协议。明确图表／界面／文案任务的必要内容范围按 SKILL.md 处理，不能因默认无文字而错误拒绝，也不把例外推广到其他片段。

让约束参与生成、筛选和成片检查，不能最后才删字／改背景。缺少真人音频只做语义估时，不TTS估时，不声称已逐字同步。缺少素材可寻找替代；影响主线且无法合理推断才问用户。

## 2. 主动研究表达，动态扩充方法

按[参考学习](reference-learning.md)从主题、情绪／态度、动作机制寻找方法；可研究独立动画、音乐影像、漫画、拼贴与日常运动，不只从企业宣传片取样。资料、图标和实现API分开记录。当前仍优先二维／图片编排，并筛掉以立体产品渲染为主体的参考；真实产品图片可作平面素材。整体组织薄弱就研究完整片段，不用一个UI缓动教程替代。相关的动作示例可用于局部试验，不能代替对本题效果的判断。

记录实际观察到的方法、可迁移的关系、需要改造的条件以及它进入哪个候选；不强制每条参考入选。无法访问的来源不是有效动态证据；换来源／文字方法依据／本地示例并明确限制。保留真实搜索记录与查看范围，禁止编造作者、镜头或参数。

## 3. 先展开表达，再展开动作

按[组合探索](exploration-method.md)做分层搜索：内容关系→组织方法→揭示顺序与交接→开中出口→运动与画面节奏。多种相关语言可以竞争；少量固定概念不是探索上限。

对内容不符或实际状态不兼容的组合先排除，不完整渲染笛卡尔积。相同排列换颜色／入场不能冒充完整方向差异。方向不确定时比较真正不同的组织或表达态度，候选数量按问题决定；已有明确方向和简单任务缩减流程，不编造错误陪衬。可先用低成本动作小样寻找潜力，再完善分镜；快稿保留影响理解的关系与接缝。

多段原创或需要提高丰富度时，按[片内丰富度设计](visual-richness.md)展开每个有效方向内部的可见事件、素材与表示形式。主导语言可以贯穿，不把它等同于全片同一版式。关键素材先检查能否取得／构建，内层变化与外层编排各有职责；简短记录在现有节拍中，不另造文档流程。

## 4. 用最低成本判断

关键构图检查主角、空间参照、遮挡和身份。需要判断时间感／连续性时做粗动稿，覆盖起态、中段、终态及主要衔接，不只做终点。约1.5秒小样只是起点，完整动作更长就覆盖完整动作。

代理对象保留影响路径和识别的尺寸、Logo区域与层序；小样与主片共享真实状态和时间配置。允许简化材质，不能把不同对象或不可能的路径隐藏在精修里。只要方案时给关键状态与分镜描述，清楚标未验证动态。

丰富度检查覆盖段落发展和主要转折，不只看一张精修海报。对照素材和事件设计，确认计划中的内层动态、表示形式与尺度／密度变化真实出现。相邻段重复有内容或节律作用时保留；仅更换颜色、名称而没有发展时回到素材或事件设计调整。

## 5. 比较并选择，必要时重新展开

按[设计检查](design-review.md)先排硬违规、事实与实际观看问题，再比较内容贴合、表达态度、对象行为、观看预期、发展潜力、节奏与实现风险。有意停顿、偏心、跳切和材料差异按作用判断，不自动修成统一顺滑。不给效果数量或文档齐全程度加审美分，不用完成度掩盖主线薄弱。

选择引用真实构图／小样及观察结果，初步偏好标待检验。不成立回到研究或组合，不叠装饰救场。默认自主决定；有充分证据仍无法可靠取舍时才带有效候选请用户选，说明具体未知。候选全坏不交给用户选坏答案。

## 6. 选择工具并交付

按[工具选择](tool-selection.md)核对用户指定、现有项目、所需能力、可编辑性和输出。技术试探可提前做，但“某模板易写”不能倒推表达。局部原型失败可换引擎或近似实现；降级前后核心关系要相同，否则换命题。

按实际工具组织素材、场景、时间轴、预览与交付，说明帧率、时长和输出规格；系列项目把内容、主题与场景分开，实际验证改参数能改变画面，变更后检查受影响镜头及接缝。实现后正常速度看真实输出，记录设计、工程和声音／文字约束各自检查结果。透明与循环按用途验证。已有明确方向／复刻／局部修订只做相关环节，不重选整片。记录使用[模板](../assets/templates/direction-record.md)，不让写文档取代制作。
