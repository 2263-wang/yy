# 保底策略：保住动画逻辑，再降低制作难度

目标是让缺少设计经验的执行者有路径可走。60张动作卡、12个配方、8个基础组件和完整示例范围不同；不宣称所有提示都能一键执行。

当前保底先满足[无说明文字动画](nontext-mg.md)：仅原生Logo字标可见、不朗读或TTS口播、不用文字版式或机械等时换图维持主线；有内容与节奏组织的图片蒙太奇允许。表达困难时减少内容或用有效候选请用户选，不能默认退回PPT。

## 最短有效路径

1. 用一句话确定片段职责、观看目标和入口／出口，保留用户规格与已定方案。
2. 原创未定主线主动[研究主题、态度或动作机制](reference-learning.md)，按[组合探索](exploration-method.md)展开相关方法，再用[分类](animation-languages.md)查细节。按真实不确定性比较有效命题，不强凑候选数量。合适的已有实现可以帮助试做关键动作，但读过示例不等于已经检验本题效果。
3. 用少量关键状态说明主角、背景参照、可见变化与承接理由。简单叠加可以只有出现、关系变化与退出，不强制运镜和复杂布局。
4. 做足以判断主要构图和接缝的粗动稿；不先做全片精修。代理映射到真实对象，大小、名称区、层序不能脱离实际。
5. 按[设计检查](design-review.md)看观看逻辑，再查工程。逻辑不成立先改方向或节拍，不靠粒子、浮动或音效盖住。
6. **默认自主取舍。** 看过证据后仍难以可靠选择，或选择主要取决于未知用户偏好时，展示2–3个有效候选、关键构图／小样、优缺点和具体不确定点，让用户选。不要每次把全部决策抛回用户，也不要硬套模板。等待选择时可整理素材和环境，暂不展开依赖该方向的主体制作。

用户已经确定方案／参考复刻／局部修改时缩小比较范围，记录理由；快稿降低证据和精修成本，不能把设计检查省为零。只要方案就写分镜，不启动渲染。

## 用库，不让库替你判断

可选命令：

```text
node scripts/select-language.mjs --content=icons --intent=state --objects=16 --duration=8 --mode=insert --format=prompt
node scripts/select-motion.mjs --assets=16 --duration=8 --mode=insert --style=calm --goal=icons
```

新入口为explore-directions.mjs（见组合探索）；以上旧命令仅检索相关语言或细化已选方向的动作配方，不读取文案／素材、不决定审美首选、不证明完成设计。主线不适配时扩充方法，不能强塞环形、网格、六层巡览。工具未定时按tool-selection.md选择，不只允许Remotion。

默认看[无说明文字动画实例](nontext-mg.md)，学习完整对象变化；[旧图谱实例](diagram-narrative.md)不再按题目关键词默认采用。三图透明叠加可参考[完整三图实例](fallback-three-images.md)，沿用时关闭额外名称与标题，只保留真实素材及其中原生Logo字标，并核对用途。

## 降级时保留什么

先写需要保住的核心关系，例如“同一个对象展开再复位”“同图谱聚焦一个关系后返回”“三个对象并列集结”。允许换实现，不允许降级后只剩无关背景和字卡却宣称核心已完成。

- 故事不清：保留主体、一次有意义变化和用途合适的出口。
- 素材下载失败：换来源、简单代码图形或示意，并说明映射；失去关键证据则改命题。
- 形态变换不可靠：换同锚点遮罩衔接，明确近似。
- 当前阶段直接关闭三维与CSS立体模拟，不先做失败再降级；使用真实产品图片、平面遮罩与二维取景，禁止用轻透视重新打开立体路线。
- 没有透明素材：先处理素材，透明编码不能自动去背景。
- 工程无法完成：准确交代已完成与未实现项，不用静帧冒充成片。

calm／balanced／dynamic 控制手法力度，不规定创作模式。安静可以有明确变化，动态也需要阅读。常规0.3–1秒是初值，镜头与持续循环另定。透明叠加按用途完整退出，无缝循环检查周期首尾。

目录、代码和数值检查不能证明低能力模型已会判断动画逻辑；真实使用反馈中分开看设计潜力、逻辑与完成度。
