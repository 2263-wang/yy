# 次要动作

每张卡的主体与终点由用户当前素材决定；时长区间为动作起步建议。代码状态 compose 与 spec-only 的含义见主索引。

## M01 · 轻浮动

实现范围：`spec-only`。需要额外的曲线、布局、绘制或专用实现；所列基础组件只是搭建线索。
- 代码状态：spec-only；基础组件：Motion。
- 起步时长：0.5–2.5 秒；氛围周期不受常规元素动作时长限制。
- 起态：主体已到位。
- 运动：用低幅慢周期位移保持氛围。
- 终态：围绕同一锚点循环。
- 注意：不能代替中段内容设计。
- 可调：主体、终点、行程、起止时刻、缓动、错峰、层序、退出可见性。
- 交接：记录终态锚点、真实包围盒、屏幕速度和 alpha；进入下一卡时逐项承接。
> 使用 M01「轻浮动」。起态：主体已到位。动作：用低幅慢周期位移保持氛围。终态：围绕同一锚点循环。主体、终点与时长服从当前方案；先做中性背景小样，再检验与前后段的锚点、边界、速度和透明度。注意事项：不能代替中段内容设计。
