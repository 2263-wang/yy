# 入场

每张卡的主体与终点由用户当前素材决定；时长区间为动作起步建议。代码状态 compose 与 spec-only 的含义见主索引。

## E01 · 托起显现

实现范围：`compose-with-primitives`。使用所列基础组件组合，并自行绑定素材、坐标和时间；不等同于完整预设。
- 代码状态：compose-with-primitives；基础组件：Motion。
- 起步时长：0.3–0.8 秒；氛围周期不受常规元素动作时长限制。
- 起态：终态下方约主体高度的8%，alpha0。
- 运动：从终点下方短距离抬起，透明度先建立，位置缓慢坐实。
- 终态：主体归位，alpha1。
- 注意：长距离上飞会抢走主体内容。
- 可调：主体、终点、行程、起止时刻、缓动、错峰、层序、退出可见性。
- 交接：记录终态锚点、真实包围盒、屏幕速度和 alpha；进入下一卡时逐项承接。
