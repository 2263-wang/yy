# 焦点与层次

每张卡的主体与终点由用户当前素材决定；时长区间为动作起步建议。代码状态 compose 与 spec-only 的含义见主索引。

## F01 · 主角前移

实现范围：`compose-with-primitives`。使用所列基础组件组合，并自行绑定素材、坐标和时间；不等同于完整预设。
- 代码状态：compose-with-primitives；基础组件：Motion。
- 起步时长：0.35–0.9秒；不作为快切图片镜头的时长下限。
- 起态：多个对象共存。
- 运动：用二维位置与大小强调主角，其他对象让位；不做深度前移。
- 终态：清楚的主次。
- 注意：用户要求并列时先确认是否允许主次。
- 交接：锚点、包围盒、速度、alpha与内容作用。
> 使用 F01「主角前移」。起态：多个对象共存。动作：用二维位置与大小强调主角，其他对象让位；不做深度前移。终态：清楚的主次。按当前内容与时长验证锚点、边界、速度和透明度。注意：用户要求并列时先确认是否允许主次。

## F02 · 局部聚光

实现范围：`spec-only`。需要额外的曲线、布局、绘制或专用实现；所列基础组件只是搭建线索。
- 代码状态：spec-only；基础组件：Motion。
- 起步时长：0.35–0.9 秒；氛围周期不受常规元素动作时长限制。
- 起态：主体均可见。
- 运动：保持主体稳定，局部光与其他对象对比发生变化。
- 终态：目标成为焦点。
- 注意：不要把遮暗层压在主角上。
- 可调：主体、终点、行程、起止时刻、缓动、错峰、层序、退出可见性。
- 交接：记录终态锚点、真实包围盒、屏幕速度和 alpha；进入下一卡时逐项承接。
> 使用 F02「局部聚光」。起态：主体均可见。动作：保持主体稳定，局部光与其他对象对比发生变化。终态：目标成为焦点。主体、终点与时长服从当前方案；先做中性背景小样，再检验与前后段的锚点、边界、速度和透明度。注意事项：不要把遮暗层压在主角上。
