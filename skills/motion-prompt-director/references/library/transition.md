# 衔接与转场

每张卡的主体与终点由用户当前素材决定；时长区间为动作起步建议。代码状态 compose 与 spec-only 的含义见主索引。

## T01 · 轮廓继承

实现范围：`compose-with-primitives`。使用所列基础组件组合，并自行绑定素材、坐标和时间；不等同于完整预设。
- 代码状态：compose-with-primitives；基础组件：ShapeMorph。
- 起步时长：0.3–0.8 秒；氛围周期不受常规元素动作时长限制。
- 起态：可变形的旧容器。
- 运动：上一对象轮廓变成下一对象的容器，再出现新内容。
- 终态：新容器与内容。
- 注意：形状拓扑不兼容时用遮罩衔接。
- 可调：主体、终点、行程、起止时刻、缓动、错峰、层序、退出可见性。
- 交接：记录终态锚点、真实包围盒、屏幕速度和 alpha；进入下一卡时逐项承接。
> 使用 T01「轮廓继承」。起态：可变形的旧容器。动作：上一对象轮廓变成下一对象的容器，再出现新内容。终态：新容器与内容。主体、终点与时长服从当前方案；先做中性背景小样，再检验与前后段的锚点、边界、速度和透明度。注意事项：形状拓扑不兼容时用遮罩衔接。
