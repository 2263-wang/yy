# 纸面世界示例

此工程是一个特定风格的可运行案例，含六张海报素材、三个内容站点及世界／摄像机分离。它不是所有动画的标准形式。

安装依赖后：

```text
npm run studio
npm run render
npm run audit
```

src/PaperWorld.js 的主体时间表 T、摄像机 CAM 读取 src/motion-budget.js；数值曲线读取 src/motion-curves.js。审计读取同一预算，不自动验证字幕、装饰或未登记动作。

原案例为 1440×1080、30fps、550 帧（18.333 秒）。主体预算支持按 fps 换算，但本复盘工程的装饰／字幕仍有字面帧号，改变 fps 前需要一起换算；不能直接承诺整支旧示例已支持任意 fps。

本次曲线边界修正改变了旧过冲形态，历史记录里的峰值与能量不代表当前输出。旧案例参数与失败过程保留在 references 中，作为相似任务的观察资料。

模板目录提供适合新工程的共用时间配置结构。完整回看仍需检查：构图、运动中的可读性、接缝、重复主角、离场残影和实际目的。

## 本次冒烟观察

用声明的 Remotion 4.0.290 渲染第 200 帧和第 431 帧，工程可运行。第 431 帧仍有大片纸面留白和较强的近似模糊，属于原案例路线／构图待调问题，不把运行通过称为视觉通过。模板第 200 帧也完成渲染；占位纸片会遮挡部分卡片，正式替换内容时需重新检查层序。此次优化未将旧示例精修为成片范例。
